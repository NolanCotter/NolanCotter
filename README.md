I build small, careful tools for the machines I run myself: homelab infrastructure that stays private by default, offline developer CLIs that never phone home, and the occasional experiment in rethinking the web from first principles.

&nbsp;

### Homelab

- **[ArrGate](https://github.com/NolanCotter/ArrGate)** — SSO and safe private networking for Docker media stacks. <sub>`Go`</sub>
- **[gatepass](https://github.com/NolanCotter/gatepass)** — Secure temporary access for private homelab services. <sub>`Go`</sub>
- **[labdns](https://github.com/NolanCotter/labdns)** — Safe, readable internal DNS names for homelab services. <sub>`Go`</sub>
- **[homelab-doctor](https://github.com/NolanCotter/homelab-doctor)** — Read-only Linux diagnostics for self-hosters. <sub>`Go`</sub>
- **[mcserver-setup](https://github.com/NolanCotter/mcserver-setup)** — A polished terminal wizard for reproducible Minecraft servers. <sub>`Rust`</sub>

### Developer tools

- **[RepoReady](https://github.com/NolanCotter/RepoReady)** — Offline release-readiness auditor for packaging, docs and Git mistakes. <sub>`Go`</sub>
- **[FlakeHarbor](https://github.com/NolanCotter/FlakeHarbor)** — Local-first analysis of JUnit test-result history. <sub>`Rust`</sub>
- **[sbom-lens](https://github.com/NolanCotter/sbom-lens)** — Explains what changed between two SPDX or CycloneDX SBOMs. <sub>`Rust`</sub>
- **[otel-pocket](https://github.com/NolanCotter/otel-pocket)** — A local OpenTelemetry receiver and viewer, no observability stack required. <sub>`Go`</sub>
- **[SecretSieve](https://github.com/NolanCotter/SecretSieve)** — Streaming secret redaction for CI logs and terminal output. <sub>`Rust`</sub>
- **[wasi-matrix](https://github.com/NolanCotter/wasi-matrix)** — Records which WebAssembly modules work on which local runtimes. <sub>`Rust`</sub>

### Experiments

- **[nexus-web](https://github.com/NolanCotter/nexus-web)** — An alternative web architecture built from first principles. <sub>`Rust`</sub>
- **[AirBridge](https://github.com/NolanCotter/AirBridge)** — Mirror and control an iPhone from Linux over AirPlay and Bluetooth. <sub>`Python`</sub>
- **[svelte-tool-dashboard](https://github.com/NolanCotter/svelte-tool-dashboard)** — New Svelte tools and libraries, aggregated daily. <sub>`Svelte`</sub>
